## 连接状态与电量的含义

- 2.4G 接收器可能返回键盘休眠前的快照，成功应答不能证明键盘刚刚上传了新电量。
- 有线标签表示读取经过 USB 有线接口，不用于断言当前按键输入一定经过这条链路。
- 蓝牙一律注明“系统缓存，连接和充电状态未确认”，不把配对记录当作在线证明，不据此触发低电量通知。
- 蓝牙不发送厂商指令。GATT 采用 `FORCE_READ_FROM_CACHE`，不为拉取电量主动唤醒或连接设备。因此当 Windows 缓存为空时也可能读不到。
- 不提供电池信息的纯有线键盘、未暴露标准电量的蓝牙固件、未收录的新协议，均不能凭空得到百分比。
- 充电期间继续显示蓝色闪电，避免固件“插电即上报 100%”造成误解。拔线后的有效读数恢复为数字。
- 目前一个托盘图标显示优先可读取的一个键盘；不是多键盘同时监控工具。

## 轻量实现

preview.3 只在同一物理迈从键盘有实际输入时自动查询，最多每 30 秒一次；发送前要求最近 2 秒内仍有匹配输入。无法取得物理设备关联时使用手动刷新。设备变化仅标记重扫，下一次按键或手动查询时按需扫描；没有闲置定时查询或扫描。蓝牙只在没有有效 USB/HID 读数时尝试，蓝牙系统 DLL 也仅在该路径需要时加载。蓝牙输入源未关联时需手动刷新缓存。无 WMI、无扫描后台常驻子进程、无官方驱动依赖。实际待机恢复仍需各型号硬件验证。

## 收集兼容性信息

`G75Battery.exe --inventory`：仅枚举已识别的 HID 接口，输出 `device-inventory.txt`；不发送设备命令，不输出序列号、蓝牙地址和设备路径。

`G75Battery.exe --probe`：尝试读取，输出 `probe-result.txt`。

`G75Battery.exe --bluetooth-probe`：只尝试 Windows 蓝牙电量属性与标准 GATT 缓存。

`G75Battery.exe --self-test`：离线验证已知帧、校验、型号过滤、状态转换和图标资源。退出码 0 表示通过；不替代真实设备测试。

## 协议依据

独立按官方 M HUB WEB 的公开脚本实现，只使用型号、命令和帧格式等协议事实，不包含官方前端代码。

- https://www.mchose.com.cn/
- https://www.mchose.com.cn/cizhou/CZ_SHARED_DATA/asset-manifest.json
- Microsoft BluetoothGATTGetCharacteristicValue / BluetoothGATTGetServices / BluetoothGATTGetCharacteristics 文档与 bthledef.h。
- Windows 蓝牙电量属性 `{104EA319-6EE2-4701-BD47-8DDBF425BBE5},2` 未形成正式公开 API 保证；不可用时尝试标准 GATT 缓存，再显示未取得电量。

新增型号应补充实机结果后再提高兼容性声明；欢迎按仓库说明提供型号、固件和诊断反馈。
