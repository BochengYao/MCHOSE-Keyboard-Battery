迈从键盘电量助手 · Windows x64 便携版

解压整个 ZIP，再双击 G75Battery.exe。无需安装 .NET、Python、编译器或官方 Hub。
程序只显示托盘图标。如藏在右下角“^”内，可拖到任务栏常显区域。

绿色数字表示电量；不超过 20% 显示红色；充电显示蓝色闪电；无读数为灰色问号。
实际敲同一把迈从键盘时自动读取，最多每 30 秒一次；闲置、开机、插拔设备或恢复系统时不主动查询。
左键托盘立即刷新，右键打开菜单。手动刷新可能唤醒键盘。
闲置或重启后保留上次读数并标注；首次使用无历史值时显示问号，按键或手动刷新后读取。
插拔充电线后的状态也在下一次按键或手动刷新时更新。
右键 → 颜色设置，可分别修改正常电量、低电量、充电三种状态的颜色。
在同一深色窗口内拖动色板、色相条，或输入 HEX / RGB；保存后立即生效并记住选择。
取消不会改变已有配色，恢复默认后需点击保存才会应用。
右键勾选“开机启动”后，当前用户登录 Windows 即自动运行；默认不会替你开启。
移动程序前取消开机启动，移动后重新运行并勾选。退出请使用菜单“退出”。

当前为多协议预览版。已实机验证 G75 V2 + 新版 2.4G 接收器（3837:3033）。
其他型号、有线和蓝牙为已加入代码但尚未逐一实机验证的路径，不保证所有固件可用。
蓝牙只显示 Windows 系统缓存，并注明连接和充电状态未确认；缓存为空就不显示百分比。
有线无电池的键盘没有电池百分比；接收器也可能返回休眠前快照。
完整兼容表见 docs\compatibility.md；详细介绍、截图和测量口径见 README.md。

统一调色界面版本机实测：使用并关闭设置后工作集 14.85–14.88 MiB，私有内存峰值 3.07 MiB。
这是短时单机采样，不是固定承诺；条件与原始数据见 docs\performance.md。
应用不联网，不上传信息，也不需要常驻官方 Hub。

读不到时先按几下键盘唤醒、点击刷新，再尝试关闭 Hub 或网页驱动连接。
诊断命令：
G75Battery.exe --inventory       枚举已识别接口，不发送设备命令。
G75Battery.exe --probe           读取一次电量，输出 probe-result.txt。
G75Battery.exe --bluetooth-probe 仅尝试蓝牙电量缓存。
G75Battery.exe --self-test       离线自检，退出码 0 通过。
G75Battery.exe --runtime-status  输出运行中实例的查询计数，不查询键盘。

待机检查：关闭官方 Hub / 网页驱动，等到键盘原本的待机时间。
程序只接收输入设备头通知，不读取或保存按键内容；闲置不会反复查询接收器。
无法关联输入设备时仅手动刷新。程序不修改键盘固件待机时间。

本项目不是迈从官方软件。当前为未签名便携包，部分 Windows 可能提示来源或 SmartScreen。
